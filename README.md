# Hebron Asrat - Portfolio Website

A beautiful, professional portfolio website for Hebron Asrat, Law Student at Arsi University.

## 🎨 Design Features

- **Feminine Theme**: Soft rose (#E8B4B8) and purple (#9B8FB8) color scheme
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Modern UI/UX**: Clean, professional layout with smooth animations
- **Smooth Scrolling**: Seamless navigation between sections
- **Downloadable CV**: Direct link to download CV

## 📋 Setup Instructions

### 1. Add Your Files

Place the following files in the `public` folder:
- `heb.png` - Your professional photo
- `CV.pdf` - Your CV in PDF format

### 2. Install Dependencies

```bash
npm install
```

### 3. Run Development Server

```bash
npm run dev
```

The website will open at `http://localhost:5173`

### 4. Build for Production

```bash
npm run build
```

The production-ready files will be in the `dist` folder.

## 🔧 Customization

To customize the website:

1. **Colors**: Edit the CSS variables in `src/App.css`
2. **Content**: Modify the JSX in `src/App.jsx`
3. **Styles**: Adjust styles in `src/App.css`
4. **Photo**: Replace `public/heb.png` with your photo
5. **CV**: Replace `public/CV.pdf` with your CV

## 📝 Notes

- Make sure your photo (`heb.png`) is square or circular for best display
- The CV should be in PDF format for easy downloading
- All links are functional and open in new tabs where appropriate
- The website is optimized for performance and SEO

## 🌟 Tips
